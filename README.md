# Tally website

Landing page for [Tally](https://github.com/Gusions/tally), a personal-finance dashboard plugin for Obsidian.

A single static page (`index.html`), no build step. Netlify publishes the repo root.

- All figures on the page are sample data.
- `index.html` has `noindex` while the site is in testing: remove the `robots` meta tag to let search engines in.
